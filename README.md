# TransportMarketing.net Static Sites

Multi-brand static website monorepo for TransportMarketing.net.

## Structure

```
/
├── redstar/       → redstar.transportmarketing.net
├── blueline/      → blueline.transportmarketing.net
├── greenpromo/    → greenpromo.transportmarketing.net
└── amberlane/     → amberlane.transportmarketing.net
```

## Deployment

All sites deploy to `/home/forge/transportmarketing.net/<brand>/` on server 64.227.66.233.

See main Laravel platform repo: https://github.com/alexkourtis98/redstar-platform
